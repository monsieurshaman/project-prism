World Settings

World Save — Builds

Upload a .json world save to restore a previously saved build.

Allowed: cube, sphere, cylinder, triangle, pyramid, torus, glass_*, mirror_*, ice_mat, rubber_mat.
Not allowed: bombs / explosives, custom 3D models.

Save Format
{
                                "version": "1.0",
                                "objects": [
                                  {
                                    "object": "cube",
                                    "location": "0, 5, 0",
                                    "rotation": "0, 45, 0",
                                    "color": "blue",
                                    "size": 1.0,
                                    "mass": 1.5
                                  },
                                  {
                                    "object": "glass_sphere",
                                    "location": [3, 8, -2],
                                    "rotation": [15, 90, 0],
                                    "color": "#00bcd4",
                                    "size": 2.0,
                                    "mass": 4.0
                                  }
                                ]
                              }

location accepts: "X, Y, Z", [X, Y, Z], or {"x":..,"y":..,"z":..}.
color accepts a hex string or a color name (red, blue, green, etc.).

Tips

The ERASE button only appears when the center cursor is aiming at an erasable object.
Hold ▲ / ▼ on grabbed controls to rapidly change hold distance.
Grab an object, then open Properties. Size, Mass and Color now edit the object you're holding. Release it and the panel returns to your spawn settings.
Aim at a Build Mode object and hold the PROPS button to edit its Size, Color and Rotation. Resizing re-snaps it to the new grid, and rotations snap to 15° steps.
SB3D Settings → Overlay → Flashlights adds a spotlight you can toggle from the HUD.
