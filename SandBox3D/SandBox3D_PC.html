World Save — Builds

Upload a .json world save to restore a previously saved build.

Allowed: cube, sphere, cylinder, triangle, pyramid, torus, glass_*, mirror_*, ice_mat, rubber_mat.
Not allowed: bombs / explosives, custom 3D models.

Save Format
{
                                "version": "1.0",
                                "objects": [
                                  {
                                    "object": "cube",
                                    "location": "0, 5, 0",
                                    "rotation": "0, 45, 0",
                                    "color": "blue",
                                    "size": 1.0,
                                    "mass": 1.5
                                  },
                                  {
                                    "object": "glass_sphere",
                                    "location": [3, 8, -2],
                                    "rotation": [15, 90, 0],
                                    "color": "#00bcd4",
                                    "size": 2.0,
                                    "mass": 4.0
                                  }
                                ]
                              }

location accepts: "X, Y, Z", [X, Y, Z], or {"x":..,"y":..,"z":..}.
color accepts a hex string or a color name (red, blue, green, etc.).

Tips

Aim at any spawned object and press V to erase it directly (no tool selected needed).
Static map objects (ground, ramp, stairs, walls, pillars) cannot be erased.
Grab an object with G, then press R to open Properties. Size, Mass and Color now edit the object you're holding. Drop it and the panel returns to your spawn settings.
Aim at a Build Mode object and hold R (or hold the Properties button) to edit its Size, Color and Rotation. Resizing re-snaps it to the new grid, and rotations snap to 15° steps.
