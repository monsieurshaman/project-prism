install prism

prism can be installed as a progressive web app (pwa) for quick access and offline capabilities.

android
on android
when you tap the install button below, your browser will generate and install prism. if android shows an "unsafe app blocked" warning, tap "more details" and then "install anyway". this is a known issue caused by the browser's webapk generator, not a problem with prism itself.
desktop_windows
on desktop
when you tap the install button below, a prompt will appear telling you to "install the app?"
